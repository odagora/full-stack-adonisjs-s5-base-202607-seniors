FlowSync es la aplicación del máster **AI4Devs** (LIDR): un starter kit
full-stack en AdonisJS 7 + React con autenticación por access tokens.

Esta documentación reúne las decisiones de arquitectura del proyecto y la
referencia de la API HTTP.
